# labs · 陪读教程的动手实验目录

这里是陪读教程所有动手实验的落脚点：

- `r1-…`～`r13-…`：`c-pi/wiki/shell/` 站（pi-test.sh 陪读 + source-resolver.ts 陪读）的实验；
- `j1-…`～`j9-…`：`c-pi/wiki/js-ts/` 站（JS/TS 语法扫盲）的实验。

每一讲会在这里建一个自己的子目录，实验产生的临时脚本都放在里面：

- 教程里的实验命令全部用**绝对路径**，在终端任何位置粘贴都能跑；
- **整个 labs 目录可以随时删掉**——教程里的命令下次会重新把它建好。不会动 `pi/` 和文档的任何文件。
